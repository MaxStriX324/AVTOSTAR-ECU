# Firmware

Planned basis: [rusEFI](https://github.com/rusefi/rusefi), not a bespoke engine-control rewrite. Board target and build must match the *actual* KiCad netlist.

- [boards/avtostar-f407](boards/avtostar-f407/): proposed STM32F407VG board port.
- [base-tunes](base-tunes/): eventual **tested engine-specific** base tunes.

No rusEFI source, binaries or usable build are included yet. See [integration plan](../docs/rusefi-integration.md) and [licensing](../LICENSING.md).
