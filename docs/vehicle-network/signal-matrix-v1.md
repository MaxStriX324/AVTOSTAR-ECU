# AVTOSTAR Vehicle Network — матрица сигналов v1

**Дата:** 2026-11-19. **Первый ПАЗ:** 2001, 12 В, карбюратор, механический спидометр, без ABS и привода пассажирской двери.  
**Назначение:** инженерная матрица проектируемых сигналов; названия символические, CAN-ID и контакты разъёмов **не закреплены**.

Уровни:
- `DIRECT` — сохранить штатную или создать проверенную независимую проводную цепь, не зависящую от Gateway/ESP32/CAN;
- `LOCAL` — датчик измеряется ближайшим устройством, значение передаётся по CAN, сигнал при потере связи INVALID;
- `BODY` — источник переключателя/выхода принадлежит кузовной сети;
- `OPTION` — новая функция, устройство на первом ПАЗ не подтверждено;
- `CANDIDATE` — функциональное назначение предлагается, требуется сверка с реальной проводкой.

## Проверка по фотографии 19.11.2026

Виден **отдельный аварийный выключатель с фиксатором**, отличающийся от красной кнопки аварийной световой сигнализации; его действие сохранять аппаратным и не перехватывать через BCM-F-IN/CAN. На правой панели визуально 11 переключателей, но назначение и полярность большей части неизвестны — все записи ниже **функциональные требования**, а не подтверждённая текущая распиновка. В комбинированном приборе два указания давления воздуха по **двум стрелкам** на шкале 0–10 кгс/см² — не путать с единственным цифровым значением. Верхний ряд имеет девять цветных сигнальных окон; точный состав неизвестных красных ламп устанавливается отдельно. Детали: [инвентаризация фото](paz-2001-dashboard-photo-inventory.md).

| LIGHT_POSITION | Переключатель | BCM-F-IN → F/R OUT | Габариты, подсветка | BODY + fail-policy |
| LOW_BEAM_REQUEST | Переключатель | BCM-F-IN → F-OUT | Ближний L/R | BODY + проверенный fallback |
| HIGH_BEAM_REQUEST / FLASH | Подрулевой | BCM-F-IN → F-OUT | Дальний L/R, световая сигнализация | BODY + прямой резерв при необходимости |
| TURN_LEFT / TURN_RIGHT | Подрулевой | BCM-F-IN → F/R-OUT | Синхронное мигание перед/зад/бок | BODY, приёмка требований отказоустойчивости |
| HAZARD_SWITCH | Выключатель | BCM-F-IN и независимая схема | Аварийная сигнализация без IGN | DIRECT резерв + BODY |
| FRONT_FOG / REAR_FOG | Переключатели | F-OUT / R-OUT | ПТФ по конфигурации | BODY, когда установлены |
| DAYLIGHT_RUNNING | Логика IGN и света | F-OUT | ДХО только когда установлены и по разрешённой схеме | OPTION |
| HORN_REQUEST | Подрулевой | F-OUT / резерв | Звуковой сигнал | BODY + анализ резервирования |
| WIPER_MODE, WASH | Подрулевой | F-OUT специальный каскад | Медл./быстр./интервал, парковка | BODY + LOCAL park input |
| BRAKE_SWITCH | Штатный датчик тормоза | Независимый тракт к задним стопам; монитор F/R | Стоп L/R без Gateway | DIRECT |
| REVERSE_SWITCH | КПП | R-OUT или независимый тракт | Задний ход, индикатор | DIRECT/LOCAL: место контакта уточнить |

| DRIVER_DEMIST / HEATER | Выключатели водителя | F-OUT/спец. релейный драйвер | Обдув стекла, отопитель | BODY, НЕ HOUSE |

## Тормоза и аварийная сигнализация

| Сигнал | Источник | Правило |
| --- | --- | --- |
| BRAKE_SYSTEM_FAULT | Фактические штатные датчики неисправности тормозов | Независимый ламповый тракт, отдельный диагностический вход; тип датчиков и наличие выяснить на ПАЗ 2001 |
| BRAKE_AIR_LOW_n | Контакт аварийного давления **только установленных контуров** | Независимые предупреждения по фактическим контурам |
| BRAKE_FLUID_LOW | Датчик бачка, если установлен | Независимое предупреждение |
| BRAKE_AIR_PRESSURE_n | Существующий манометр и опциональные преобразователи | Штатный пневматический прибор оставить, цифровые значения только как дополнение |
| ABS_STATUS | **Отсутствует** на первом ПАЗ | Запретить все ABS-каналы/лампы в конфигурации 2001 |
| DOOR_ACTUATOR | **Отсутствует** на первом ПАЗ | Запретить выходы электропривода пассажирской двери |

## Данные оборудования и диагностика

| Сигнал | Производитель | Потребитель | Примечание |
| --- | --- | --- | --- |
| OUTPUT_ACTUAL_ON / OUTPUT_CURRENT | Каждый BCM-OUT | CLUSTER через BODY, Gateway | Запрос ≠ реальная подача напряжения/тока |
| OUTPUT_FAULT | Каждый BCM-OUT | CLUSTER, Gateway | ID платы, канал, локация, open-load/overcurrent/overtemp |
| MODULE_HEARTBEAT | Каждый узел | CLUSTER/Gateway | UID, revision, firmware, uptime, состояния |
| CAN_BUS_OFF / RX_TIMEOUT | Локальный интерфейс | Диагностика | Состояние связи и время последнего валидного кадра |
| SENSOR_VALIDITY / AGE | ECM-IO / SENSOR-IO | CLUSTER | Устаревшие значения не показывать как актуальные |
| POWER_FAIL / UV / OV | PDU/модули | CLUSTER/Gateway | Раздельные пороги профилей 12/24 В |
| HOUSE_STATUS | HOUSE-IO | Gateway / HOUSE UI | Ни один бытовой отказ не отменяет кузовные приборы |

## Правила приоритета и источников

1. Для каждой переменной назначить **один источник истины** в каждом конкретном профиле автомобиля: RPM сейчас ECM-IO, после ECU — ECU; альтернативный резерв отдельно с меткой.
2. Единицы измерения, знак, raw→physical, частоту, допустимый возраст, диапазон и timeout держать в DBC/реестре сигналов; в этой таблице **нет** утверждённых CAN-ID, циклов или pinout.
3. Запрос BCM-F-IN не приравнивать к реально включённому свету, которое проверяет выход BCM-OUT.
4. Ранний этап: старые показометры/критические лампы остаются работоспособными при отключённых новых модулях.
5. Перед переходом на электронные стрелочные приборы требуется обмер датчиков, калибровочные точки, тип выходного драйвера и испытания fail-state.
6. 12/24 В относятся к аппаратной базе; лампы/приборы всегда должны соответствовать своему номинальному напряжению.

## Приоритет проверок на ПАЗ

- Фото панели, всех контрольных ламп при тесте, шильдики приборов, вид с обратной стороны, список свободных разъёмов;
- Замеры уровней штатных сигналов IGN/START/стоп/повороты/лампа генератора;
- Выяснить реальную схему датчиков масла, ОЖ, топлива, тормозов;
- Перечень фонарей, мощностей, способы подключения массы, питание переднего/заднего распределительных узлов;
- Маркировка КПП/раздатки и реальная кинематика троса спидометра.
