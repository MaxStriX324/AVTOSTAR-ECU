# Документы по ПАЗ-3206: каталог источников

## Что требуется для дальнейшей схемотехники

1. Подлинная электрическая схема ПАЗ-3206 / ПАЗ-3205 около **2001 года**, применимая к конкретной комплектации и мотору.
2. Фактическая ведомость нагрузок, их мощность и имеющиеся жгуты/предохранители.
3. Фото места привода тросового спидометра, шильдиков КПП/раздатки и датчиков.
4. Отдельная проверка существующих независимых цепей стоп-сигналов, тормозных аварийных сигналов и аварийного выхода.

См. также [архитектуру интеграции ПАЗ](../paz-3206.md).
