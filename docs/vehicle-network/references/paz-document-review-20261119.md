# Разбор найденной документации ПАЗ для AVTOSTAR Vehicle Network

**Дата анализа:** 2026-11-19  
**Статус:** извлечение инженерной информации из PDF владельца; **не подтверждает схему проводки конкретного экземпляра ПАЗ-3206**.

## Первичные документы (загружены владельцем в диалог)

1. `avtobus_paz_3206110 (1).pdf` — ООО «Павловский автобусный завод», «Автобус ПАЗ 3206-110», `3206-110-3902010 РЭ`, 2012 г., **16 страниц**. Это дополнение к руководству ПАЗ-32053, а не полная электросхема кузова.
2. `электросхема паз.pdf` — фрагмент `320405-3902010 РЭ`, **48 страниц**, схемы **других моделей**: ПАЗ-320405-04 (Vector NEXT, механическая КПП, PDF стр. 1–14, печатные стр. 135–148), ПАЗ-320445-04-110-02 (АКПП с оборудованием, PDF стр. 15–30, печатные стр. 149–164), ПАЗ-320405-14 (ГБО, PDF стр. 31–48, печатные стр. 165–181).

**Принцип:** из второго источника допускается извлекать только типовые функциональные связи и состав потребителей, **не** штатную распиновку/проводники/номиналы/24-вольтовые решения для 12-вольтового ПАЗ-3206. Окончательное решение по конкретному автобусу — по его VIN/комплектации, реальной электропроводке и релевантной заводской схеме ПАЗ-3206/32053.

## Из PDF по ПАЗ Vector NEXT: функциональные схемы для архитектуры, но **не** для монтажа в ПАЗ-3206

Фрагмент Vector NEXT содержит обозначения `F43` (электрощит шасси), `F44` (электрощит автобуса), `F45` (реле/предохранители панели приборов). Это хороший **архитектурный** пример зонального разделения. Он не подтверждает существование CAN-BCM в ПАЗ-3206.

## Уточнение нашей архитектуры

1. **ECM-IO:** входы `VSS_TC`, `VSS_GB`, `ENGINE_RPM`, опциональный концевик сцепления и высокоомный монитор `FRONT_AXLE_ENGAGED`; возможны отдельные `TRANSFER_LEVER_POSITION`, `PARK_BRAKE`, `LOW_AIR_PRESSURE` при согласовании со штатной цепью.
2. **Коэффициенты раздатки:** создать профиль `PAZ_3206_110_2012_REFERENCE`: `i_tc_high=1.0`, `i_tc_low=1.982`. Это **заводские значения из документа** для соответствующей модификации, не окончательная калибровка конкретного автобуса.
3. **Блоки BCM-F/R-OUT:** использовать функции освещения из схем Vector NEXT только как проверочный список, а каналы и сечения проектировать по реальной машине; задний блок должен иметь независимый тракт стопов.
4. **ABS и тормоза:** не объединять их управляющие сигналы со световыми выходами и Gateway. Даже мониторинг статуса требует входа, не нагружающего исходную цепь.
5. **HOUSE CAN:** отопление/освещение жилой части не должно наследовать 24-В цепи дверей и салона чужого автобуса.

## Какие документы ещё нужны для принципиальной схемы ПАЗ

- Заводская электрическая схема **именно ПАЗ-3206-110/32053 применимого года, двигателя и комплектации**, особенно питание, габариты, стоп-сигналы, аварийка, приборы, ABS.
- Фото и маркировки КПП и раздатки, точный механический привод троса, электрические параметры будущих двух датчиков.
- Список реальных установленных фонарей/ламп, величины токов, точки массы и существующие разъёмы.
- Фотографии или схема штатной тормозной сигнализации и цепи отключения ABS при подключении переднего моста.

**Не переснимать без проверки:** фото в PDF чужой модели, провода, их цвета, контакты и предохранители; их можно использовать только для функциональной декомпозиции, а не для подключения.
